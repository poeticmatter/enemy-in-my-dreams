# Enemy in My Dreams

A solo card game where your deck is your health, with a balance simulator and heuristic bots.

- **Play:** https://poeticmatter.github.io/enemy-in-my-dreams/
- **Balance report:** [REPORT.md](REPORT.md) · rules as simulated: [RULES.md](RULES.md) · iteration log: [DESIGN_JOURNAL.md](DESIGN_JOURNAL.md)

```
npm install
npm run sim -- --set v6     # simulate every bot and rules variant
npm test
npm run dev                 # play locally
npm run deploy              # build and publish to GitHub Pages
```
